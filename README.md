# Scalpers: Rise of the Deckromancers

A co op or competitive roguelike Trading Card Game played in First Person. Teams of players will explore procedurally generated maps while summoning monsters, casting spells and placing traps in search for high value booster boxes. 

Each map will be a different themed location with unique cards, monsters and spells. Teammates will be able to trade cards among themselves, use them in their own decks or cash them in for money.
